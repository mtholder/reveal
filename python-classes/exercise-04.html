This is advanced.

  1. Set EXERCISE_4 to True
  2. Create new classes that have Organism as parents and do slightly differnt things - for example an Herbivore class and a Carnivore class.
  3. Uncomment the org_class_list = [] line, and fill in the names of your different types of organism sub-classes.

Now the type of organism is randomly selected from org_class_list when the simulation starts

When done see index of exercises
