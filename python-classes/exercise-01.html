There is a lot of code there. You don't need to understand it all. Here are the basics:

  1. This is the start of a simulator of organisms moving around a landscape. The landscape is grid. A class Landscape is written for you to hold all of the Organisms and all of the patches of habitat in the grid.
  2. There is a Patch class. Each patch of habitat is an instance of that class.
  3. The Organism class is not written. You need to write an Organism class
  4. You should look at the main to see what the program does

If you were to read every bit of code (I don't recommend doing that), you'd see that:

  • Organism instances are created in Landscape.create_organisms with a call
    Organism(rand_patch)
    where rand_patch is a Patch instance where the organism lives at the start
  • In do_random_organism_movement to control dispersal, the code expects each organism to have a postive integer in an attribute
    num_patches_to_disperse
  • Patches keep track of what organisms are in them, if you call the patch's
    add_organism
    and pass in the organism.

So... At the top you need to replace CODE HERE with python code to

# Create a new Organism class
# create an initializer that takes a Patch 
#   instance as an argument and stores
#   it as a "patch" attribute
# Set a "num_patches_to_disperse" attribute
#   to be a positive integer (not huge, let's say < 10)
# Note that there is an add_organism method in Patch
#   as the last step in the initialize routine for 
#   the Organism, each instance should add itself
#   to its patch using this method.
