Using the same code, uncomment the line with self.do_rand_interactions()

To make the program work now, you have to:

  1. Add a boolean alive attribute to the Organism with the initial setting being True.
  2. Add a do_interaction method to Organism that takes another organism in the same patch as an argument.

I'd recommend having some interaction like:

  • each organism starts with a random energy (random.random() returns a random number between 0 and 1),
  • in the do_interaction, one organism tries to eat the other. If it has higher energy, it succeeds.
  • If an organism dies, you should remove it from its patch and set its alive attribute to False
